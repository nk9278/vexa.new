# VEXA Installation Guide

1. Clone or extract the repository directly into your web-root (e.g. `public_html`).
2. Run the provided `database.sql` script within phpMyAdmin or your MySQL CLI to build table architecture.
3. Configure `config/constants.php` with your specific MySQL credentials.
4. Open your browser and navigate to `yourdomain.com/super-admin/login.php` to login with the seeded super admin profile.
5. Create your first Agency account from the dashboard to begin standard workflows.
